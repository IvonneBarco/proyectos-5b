Proyecto LearnBetter API

Sistema orientado a la Mejora del aprendizaje a partir del analisis de notas con el fin de mejorar el rendimiento académico del estudiante.

Esta aplicación permite analisar las notas de estudiantes, identifica las temáticas en las que el estudiante tiene dificultades y genera un plan de estudio personalizado.
