Proyecto LabHealth API

Sistema orientado a la recepción e interpretación de resultados de exámenes de laboratorio clínico. La aplicación permite gestionar información de pacientes, órdenes de laboratorio, exámenes y resultados, además de identificar valores fuera de los rangos de referencia y generar alertas de anormalidad

La aplicación permite gestionar pacientes, órdenes de laboratorio, exámenes y resultados, estableciendo una relación entre cada uno de estos componentes. Para cada examen se pueden registrar valores de referencia y comparar automáticamente los resultados obtenidos con los rangos establecidos.
