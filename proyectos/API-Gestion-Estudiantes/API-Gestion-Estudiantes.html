API de Gestión de Estudiantes

API REST para la gestión de estudiantes, cursos e inscripciones en una institución educativa

Descripción del proyecto

Qué resuelve la API y para quién

API REST desarrollada con NestJS que permite gestionar estudiantes, cursos e inscripciones en una institución educativa. La API ofrece endpoints bien estructurados para realizar operaciones CRUD, validaciones de datos con class-validator, persistencia en PostgreSQL usando TypeORM y documentación interactiva mediante Swagger.

Funcionalidades principales

Operaciones que ofrece la API

Gestión de Estudiantes

Crear, listar, actualizar y eliminar estudiantes del sistema.

Gestión de Cursos

Crear y listar los cursos disponibles para inscripción.

Inscripciones

Relacionar estudiantes con cursos y consultar inscripciones.

Validaciones

Validación de datos de entrada con class-validator.

Endpoints de la API

Rutas disponibles para consumir el servicio

Estudiantes

  • POST /students
  • GET /students
  • GET /students/:id
  • PATCH /students/:id
  • DELETE /students/:id

Cursos

  • POST /courses
  • GET /courses

Inscripciones

  • POST /enrollments
  • GET /students/:id/courses
