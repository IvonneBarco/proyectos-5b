DonaGest

Gestión y control de donaciones destinadas a zonas afectadas por desastres naturales

Descripción del proyecto

Qué resuelve DonaGest y para quién

API de gestión de donaciones para desastres naturales: permite registrar donaciones masivas, controlar el stock de productos recibidos, identificar quién realiza cada donación, registrar las cantidades donadas y gestionar el destino de los recursos hacia las zonas afectadas.

Funcionalidades principales

Lo que el sistema permite hacer al usuario

Registrar donaciones

Permite registrar quién realiza una donación, los productos entregados y las cantidades correspondientes.

Control de stock

Permite controlar los productos recibidos y las cantidades disponibles para su posterior distribución.

Gestionar destinos

Permite registrar y gestionar las zonas afectadas que recibirán los recursos disponibles.

Gestionar entregas

Permite registrar el destino de los recursos y controlar la entrega de productos a las zonas afectadas.
