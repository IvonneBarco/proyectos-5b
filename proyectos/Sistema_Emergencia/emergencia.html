Sistema de Emergencia

Descripción del proyecto

Es un sistema diseñado para registrar, gestionar y supervisar situaciones de emergencia de manera rápida y organizada. Permite reportar incidentes, administrar recursos, asignar personal de atención y realizar seguimiento a cada caso, facilitando una respuesta oportuna y mejorando la seguridad de las personas.
