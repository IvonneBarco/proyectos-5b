SISTEMA DE ALQUILER DE BICICLETAS

El Sistema de Alquiler de Bicicletas es un proyecto academico desarrollado por estudiantes del grado 5B. El objetivo es crear una pagina web donde los usuarios puedan alquilar bicicletas de forma facil y rapida. Desde la plataforma se puede ver cuales bicicletas estan disponibles, registrar un alquiler con fecha de inicio y devolucion, calcular el valor segun el tiempo de uso y ver el historial de prestamos. Este proyecto busca promover el uso de la bicicleta como medio de transporte y ayudar a mejorar los procesos que antes se hacian a mano.
