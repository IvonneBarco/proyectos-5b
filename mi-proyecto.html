Sobre el proyecto

Vamos a hacer un proyecto en Nest.js el cual recibe una URL larga, genera un código único de 6 caracteres y lo guarda en memoria relacionándolo con la URL original. Cuando alguien visita ese código, el servidor lo busca y lo redirige automáticamente (HTTP 302) hacia la página web original.

POST /shorten: recibe la URL larga en el cuerpo de la petición (JSON), genera el código aleatorio, lo almacena en memoria y responde con la nueva URL acortada.

GET /:code: busca el código en memoria. Si lo encuentra, responde con un código de estado 302 Found para redirigir la navegación hacia la URL original. Si no existe, devuelve un error 404 Not Found.
