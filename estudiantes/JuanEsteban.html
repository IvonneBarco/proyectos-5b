Investigacion: Trabajo en el desarrollo de un sistema de inteligencia artificial orientado a la predicción y soporte ante ciberataques. El proyecto busca analizar patrones de comportamiento anómalo en sistemas y redes mediante modelos de IA, con el fin de anticipar posibles vectores de ataque, generar alertas tempranas y brindar recomendaciones de respuesta

Proyectos: Herramienta de línea de comandos y GitHub Action para el análisis automatizado de seguridad en Pull Requests. Combina análisis estático (SAST) sobre 7 categorías CWE, escaneo de vulnerabilidades conocidas en dependencias mediante OSV.dev, recuperación aumentada por generación (RAG) sobre una base de conocimiento OWASP/CWE, y razonamiento con modelos LLM a través de Amazon Bedrock para filtrar falsos positivos antes de publicar los hallazgos como comentario estructurado en el PR. El sistema permite personalizar el análisis según el stack y las convenciones de cada equipo mediante un perfil de configuración, reduciendo el ruido de alertas y acelerando la revisión de seguridad en el ciclo de desarrollo.
